## 🚀 Start here

1. Read the model’s supported embodiments, action representation and checkpoint terms.
2. Check its documented inference / fine-tuning setup and compute requirements.
3. Evaluate on the project’s supported task before adapting to a new robot.

Read the [engineering guide](GUIDE.md) for a practical selection checklist. [resources.json](resources.json) contains the structured entries.
