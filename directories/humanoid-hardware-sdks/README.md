## 🚀 Start here

1. Confirm the hardware generation, firmware and communication protocol.
2. Match the SDK release and examples to that exact platform.
3. Inspect the API / state messages first and keep each platform’s dependencies separate.

Read the [engineering guide](GUIDE.md) for a practical selection checklist. [resources.json](resources.json) contains the structured entries.
