## 🚀 Start here

1. Choose the ROS distribution and middleware specified by the source project.
2. Build each collection in its own documented workspace; legacy ROS and ROS 2 differ.
3. Inspect interfaces, topics and robot description paths before integrating another package.

Read the [engineering guide](GUIDE.md) for a practical selection checklist. [resources.json](resources.json) contains the structured entries.
