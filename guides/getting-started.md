# 🚀 Getting started with the SSRobotics ecosystem

Start from the [main Hub](https://github.com/SSRobotic/humanoid-robot-hub) or the [searchable directory](https://ssrobotic.github.io/humanoid-robot-hub/). Choose a focused category, then follow the original project’s setup instructions.

## Models & visualization

[🦾 Humanoid models](https://github.com/SSRobotic/humanoid-models) connects DOBOT Atom, TienKung and upstream MuJoCo models. The local Unitree model snapshot contains A1 / Aliengo / AliengoZ1; modern G1 / H1 models are available through the current upstream Unitree project.

## Simulation & control

[🌐 Simulation](https://github.com/SSRobotic/humanoid-simulation), [⚙️ whole-body control](https://github.com/SSRobotic/humanoid-whole-body-control) and [📡 ROS integration](https://github.com/SSRobotic/humanoid-robot-hub/tree/main/directories/humanoid-ros2) have separate engineering guides. Match software, robot generation and middleware to the source instructions.

## Robot learning

[🧠 Robot learning](https://github.com/SSRobotic/humanoid-robot-learning), [💬 VLA](https://github.com/SSRobotic/humanoid-robot-hub/tree/main/directories/humanoid-vla) and [💾 datasets](https://github.com/SSRobotic/humanoid-datasets) organize algorithms, model projects and demonstration data. Source compatibility and data access conditions remain with each project.

## Vision, manipulation & teleoperation

[👁️ Vision](https://github.com/SSRobotic/humanoid-vision), [🤏 manipulation](https://github.com/SSRobotic/humanoid-manipulation) and [🎮 teleoperation](https://github.com/SSRobotic/humanoid-teleoperation) cover supporting workflows. The DOBOT Vision collection is specific to EG0053-01 workstations; Magician and legacy Go1 material are supporting platform references.

## Explore all repositories

See [🗺️ repository-map.md](repository-map.md) for the complete ecosystem. Directory repositories contain resource lists and guides; platform repositories contain the existing code collections. The source snapshots in this Hub remain available as historical references.
