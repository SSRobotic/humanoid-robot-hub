## 📝 Record your setup

| Item | Record before experimenting |
| --- | --- |
| Robot / embodiment | Platform, joint layout and supported generation |
| Software | Source commit, dependency versions and operating system |
| Interfaces | Observation / action representation, topics and frame conventions |
| Data / assets | Source URL, license, formats and split / calibration details |
| Evaluation | Task, input conditions and a reproducible baseline |
